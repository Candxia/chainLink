## 四、启动方式

### 前提条件
- MySQL 数据库
- Redis (可选)

### 1. 初始化数据库
```sql
mysql -u root -p < backend\manifest\sql\schema.sql
```

### 2. 启动后端
```bash
cd backend
go run main.go
# 服务监听 http://localhost:8099
```

### 3. 启动前端 (开发模式)
```bash
cd frontend
npm run dev
# 访问 http://localhost:3000
# 登录: admin / admin123
```
