# 链环系统生态 — MVP 需求摘要

## 一、项目概述
基于区块链技术的供应链溯源管理系统 MVP 版本。实现产品从生产到销售的全链路追溯。

## 二、核心功能模块

### 1. 用户与权限管理
- 多角色管理：超级管理员、企业管理员、质检员、普通用户
- RBAC 权限模型
- JWT 认证
- 企业信息管理

### 2. 产品溯源管理
- 产品登记（名称、规格、批次）
- 溯源信息录入（生产、加工、质检、物流）
- 溯源二维码生成
- 产品溯源查询（基于产品 ID/批次号）

### 3. 供应链管理
- 供应商管理（资质审核、评级）
- 物流追踪（运输节点记录）
- 仓储管理（入库/出库/库存）
- 订单管理

### 4. 区块链集成
- 溯源信息上链记录
- 区块浏览器
- 交易记录查询
- 智能合约管理（基础版）

### 5. 系统管理
- 配置管理
- 操作日志审计
- 系统通知
- 数据统计看板

## 三、技术栈
- **后端**: GoFrame v2 (Go)
- **前端**: Vue 3 + Element Plus (Element Admin 模板)
- **数据库**: MySQL + Redis
- **区块链**: 本地模拟链 / 联盟链接口
- **部署**: Docker
